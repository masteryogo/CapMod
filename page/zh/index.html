架构

统一架构。三大接口。

CLI、MCP 与原生 Agent 均为构建在单一共享核心之上的轻量包装——零重复逻辑。

  ┌─────────────────────────┐
  │ 人类工程师 (CLI)        │──────┐
  │ cap data / train / eval │      │
  └─────────────────────────┘      │      ┌──────────────────────────────────┐
  ┌─────────────────────────┐      │      │ Core Toolkit (共享核心)         │        ┌─────────────────┐
  │ 外部 Agent (MCP 工具)   │─────┼─────►│ • data (inspect/validate/prep)   │        │ 生态集成        │
  │ Claude Code · Codex     │      │      │ • training (train/tune/compare)  │───────►│ MLflow · DVC    │
  └─────────────────────────┘      │      │ • evaluation (metrics/sanity)   │        │ W&B · Docker    │
  ┌─────────────────────────┐      │      │ • registry (versioning/lineage) │        │ Vertex AI       │
  │ CapTrain 原生 Agent     │──────┘      │ • inference (batch/serving)      │        │ AWS SageMaker   │
  │ plan → exec → analyze   │             │ • pipeline (orchestration)      │        └─────────────────┘
  │ → iterate (内建防护栏)  │             └──────────────────────────────────┘
  └─────────────────────────┘

功能

ML 生命周期的每个阶段

从数据检查到生产监控。CLI、MCP 或原生 Agent 均可调用相同的共享能力。

数据检查与验证

Schema 分析、统计指标、异常检测、数据质量规则、类型检查与空值校验。

CLI cap data inspect
MCP inspect_dataset()
Agent “检查数据集是否存在泄漏与空值”

训练与超参调优

执行模型训练与微调，支持超参空间探索，输出结构化实验记录与分析指标。

CLI cap train
MCP train_model()
Agent “训练基线模型并调优超参数”

评估与基准对比

多模型横向横评、子群体切片评估、置信区间计算与性能基准基线对照。

CLI cap eval
MCP evaluate_model()
Agent “按切片细分评估并对比基线”

模型注册与血缘

版本控制、元数据注册与血缘追踪。自信可靠地将优质模型推进到生产阶段。

CLI cap model register
MCP register_model()
Agent “注册最优模型并锁定数据版本”

推理与部署准备

批量离线预测与实时推理服务。自动生成 Dockerfile 与容器化部署准备。

CLI cap infer serve
MCP predict() / serve()
Agent “构建 Docker 容器并启动推理服务”

流水线编排

从数据到部署的端到端自动化流水线。YAML 声明式配置，100% 确定性复现。

CLI cap pipeline run
MCP run_pipeline()
Agent “执行完整流水线并通过论证门禁”

原生 AI AGENT

专为 ML 生命周期打造的原生 Agent

算法与机器学习工程师只需用自然语言描述任务，Agent 即可自动且严谨地规划、执行、分析并迭代 ML 实验。

核心职责 12 个端到端关键职能
01

数据集分析与验证

自动解析数据结构、分布特征与脏数据规则，拦截质量隐患。

02

EDA 与特征预处理

自动化探索性数据分析、缺失值插补、特征编码与切分策略清洗。

03

基线模型构建

快速构建启发式或极简基准模型，为后续复杂实验迭代锚定性能基准线。

04

模型训练与微调

执行经典模型、深度学习架构与微调训练（Fine-tuning），保持稳定收敛。

05

超参数调优

多策略超参数空间探索，结合早停机制与贝叶斯优化，最大化模型收益。

06

模型评估与多模型横向对比

统一多维评估体系，生成模型胜负排行榜与置信度差异分析。

07

实验执行与全流程追踪

全自动无干预调度实验流程，细粒度跟踪损失曲线、资源开销与状态。

08

实验版本控制与追踪管理

深度绑定代码快照、数据快照与环境配置，保障历史实验 100% 可复现。

09

过拟合与数据泄漏诊断

深入学习曲线与特征依赖关系，及时揪出虚假高分与隐蔽的穿越泄漏。

10

最终模型遴选

权衡准确率、推理延迟、资源开销与业务切片表现，科学决策上线候选。

11

实验洞察报告自动生成

自动归纳实验推演逻辑、调优拐点与结论摘要，生成供工程团队审阅的报告。

12

推理服务与生产部署准备

产出生产级 Docker 镜像、API 服务接口封装与监控打点配置，就绪上线。

专业防护栏

Agent 专业工具箱与“论证检查门禁”

与仅能运行任意 Python 脚本的通用代码 Agent 有着本质不同：CapTrain 内建领域级防护栏，在错误与虚假高分进入报告前将其彻底拦截。

数据完整性 (Data Integrity)

防范根源缺陷
check_leakage()
check_split_validity()
check_duplicate_rows_across_splits()

拦截目标值隐式泄漏、切分策略违规（如时序穿越）、训练/测试集样本跨集重叠等致命错误。

评估合理性 (Evaluation Sanity)

严谨度量
suggest_metric()
baseline_comparator()
confidence_interval()

纠正与业务场景不匹配的评价指标，拦截未超越平凡基线（Trivial Baseline）的伪优化，避免将随机噪声当成信号。

过拟合/欠拟合诊断 (Diagnostics)

收敛深度诊断
learning_curve_analyzer()
feature_importance_sanity_check()

自动化诊断训练集与验证集泛化间隙，审查异常主导特征，揪出伪装在高准确率下的严重特征泄漏。

可复现性与溯源 (Provenance)

全链条锁定
experiment_diff()
data_version_lock()

精准对比不可追踪的参数与环境差异，锁定不同数据快照版本，杜绝因数据底座不同步导致的无效对比。

论证检查门禁 (The Justifier)

流水线强制门禁 · 非单纯工具

在向工程师汇报最终结论前，Agent 必须强制通过由结构化检查点构成的逻辑门禁。杜绝盲目自信——把单纯的“准确率达到 94%”，转变为“准确率 94%，且附带无可辩驳的证据链与论证依据”，所有论证过程全程沉淀于实验日志。

✓ 切分策略无误
✓ 评估指标合理
✓ 显著跑赢基线
✓ 绝无数据泄漏

工程准则

CapTrain 像资深机器学习工程师一样思考

超越演示 Demo，践行 10 大生产级工程原则，赢得算法团队在关键业务流中的深度信任。

01

成本预估与预算控制

耗时与大规模算力训练前自动调用 estimate_cost()，设定支出上限，超出阈值强制需人工审批。

02

切片级细粒度评估

默认按核心业务子群体与少数派样本切片展开多维评测，无死角揭示被整体指标掩盖的盲区。

03

默认保留人工介入 (HITL)

在不可逆的关键操作（如生产上线模型晋级、关键训练集筛选确立）前设置强制性人工确认检查点。

04

数据单元测试自动化

针对每一个新数据快照自动执行 Schema 模式、数据漂移（Drift）与异常空值分布检测。

05

严格的代码沙箱隔离

Agent 生成与运行的代码限制在安全隔离沙箱中，杜绝非受控的网络访问与越权文件写入。

06

深度兼容现有技术栈

与 MLflow、DVC、W&B、Vertex AI、SageMaker 深度组合，赋能既有基础设施而非粗暴替代。

07

Agent 决策全链路可解释性

透明沉淀“为何选择该模型架构与超参空间”的推演决策日志，与模型自身的解释性（SHAP 等）同等重视。

08

秒级快速回滚机制

秒级精准回退至任意历史模型版本、数据切分与配置状态，版本链条清晰可溯。

09

部署后持续跟踪与监控

将在线数据漂移、模型概念衰减（Concept Drift）与业务指标衰退追踪纳为常态化闭环。

10

原生支持团队多人协作

实验记录、论证结论与洞察报告对全团队公开透明，不再禁锢于单个工程师本地终端。

路线图

多主线并行推进

核心、CLI、MCP 与原生 Agent 同步研发，而非延后拼装的附带功能。透明、社区驱动。

基础架构主线 (Foundation)

进行中

核心包骨架结构、pyproject.toml 依赖定义、GitHub Actions CI/CD 自动化流水线、测试套件与类型检查。

数据工程层主线 (Data Layer)

进行中

cap data inspect、validate 与 prepare——构建从数据清洗到特征切分的坚实底座。

训练与评估引擎主线 (Training & Eval)

进行中

cap train、cap eval、多实验横向对比差异分析（diff）及统一基准评测。

注册表与推理主线 (Registry & Inference)

规划中

模型版本生命周期管理、全链路溯源、批量预测与基于 Docker 容器化的轻量级实时推理服务。

MCP 外部 Agent 接口主线 (MCP Interface)

进行中

将核心所有工程能力封装为标准化 MCP 协议工具集，供 Claude Code、Codex 等外部编码 Agent 直接调用。

编排与生产监控主线 (Orchestration & Monitoring)

规划中

端到端声明式流水线编排、生产环境数据漂移持续检测、概念衰退预警与实时业务指标联动。

Agent 专业工具集与论证门禁 (Agent Toolkit & The Justifier)

进行中

内建数据泄漏检查、切分策略合法性验证、指标合理性校验、过拟合诊断工具与“论证检查门禁”强制校验。

Agent 上下文与记忆主线 (Memory & Context)

规划中

项目全貌感知、历史实验轨迹沉淀、跨会话会话上下文保持，确保 Agent 具备长期工程记忆。

原生自主 Agent 主线 (Native Autonomous Agent)

规划中

实现规划（Plan）→ 执行（Execute）→ 分析（Analyze）→ 迭代（Iterate）的完整闭环，全自主驱动机器学习实验。
